# Legacy citation and reference roles become modern MyST `@key` / `@label`

# link to a target, which is `@x`. `{doc}` becomes a plain link to the page.

# A cross-document reference outside a Quarto book is written as a link

# link to the heading renders the same as `{ref}`.
